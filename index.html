How to edit this software on GitHub
To update your live web app after any change:
1. Go to your GitHub repository → click index.html
2. Click the pencil icon (Edit this file) at the top right
3. Make your changes in the editor
4. Scroll down → click "Commit changes" → your site updates in 1–2 minutes

To add items permanently to your lists (optional — the Settings tab is easier):
In the file, near the bottom, find this line: var LISTS = {personnel:[], packaging:[], skus:[], products:[]};
Add names inside the square brackets like this: personnel: ["Apio Sarah", "Okello James", "Namutebi Ruth"]

To add a new field to the entry form:
1. Find a similar field in the HTML and copy its block
2. Give it a new unique id (e.g. id="e-myfield")
3. In the saveEntry() function in the script, add: myfield: gv('e-myfield'),
4. Add it to the table headers and row in renderRecords() and the CSV export functions

To change the app title: Find <title>Production Tracker</title> and the <h1> tag and edit the text.

To share the app with your team: Give them your GitHub Pages link. Each person's data stays on their own device. Use "Export all records to CSV" from each device and merge in Excel to combine records.
