🖥 Multi-User Server Setup
Run server.js on your computer and all staff connect via your IP address. Data stored in one shared data.json file.
1
Install Node.js from https://nodejs.org (LTS version) on the server computer.
2
Place index.html and server.js in the same folder, e.g. C:\SEWECO-Tracker\
3
Open a terminal in that folder and run:
npm install express cors
4
Start the server:
node server.js
Your network IP will be displayed. Keep this window open.
5
Connect all computers: Open a browser and go to http://YOUR_IP:3000 on every device. All data is now shared in real time.
